## The Word

> fridgehope: opening the fridge again, hoping a better snack magically appeared since you checked ten minutes ago.

## Why this word

Everyone knows the ritual: you checked the fridge ten minutes ago, nothing appealed, and yet you open it again as if the shelves have restocked themselves in your honour. English has no word for that stubborn, snack-driven optimism. "Fridgehope" is a transparent compound of two everyday words — sayable, spellable from sound alone, and memorable — and its definition lands in a single reading: one action, one hope, and the comic ten-minute gap that gives the joke away.

## How to run

```bash
python3 main.py
```

This writes `/output/entry.txt` containing the single-line entry. Set the `OUTPUT_DIR` environment variable to override the target directory:

```bash
OUTPUT_DIR=/tmp/out python3 main.py
```
